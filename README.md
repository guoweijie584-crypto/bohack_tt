# bohack_tt

黑客松小游戏作品集：几款单文件 HTML5 Canvas 网页游戏，以及一份游戏改版意见素材包。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | **源能斗士 · AETHER VANGUARD**（主版本） |
| `index(1).html` | **源能斗士 · AETHER VANGUARD II**（续作 / 扩展版） |
| `index(2).html` | **源能斗士 · AETHER VANGUARD**（另一迭代版本） |
| `blade.html` | **百刃 · BLADE ORBIT 500**（打碎木栅栏得刀片，消耗刀片击杀怪物换金币） |
| `游戏改版意见.zip` | 改版意见素材：boss 参考图、人物参考图等 |

## 运行方式

所有游戏都是独立的单个 HTML 文件，无需安装依赖、无需构建，直接用浏览器打开即可：

```bash
open index.html        # macOS
# 或者双击文件，用 Chrome / Edge / Safari 打开
```

## 操作说明

- **源能斗士**：`WASD` 移动，鼠标左键攻击，`空格` 技能，`F` 与源能枢纽交互（补给 / 切换路线 / 传送 / 竞技场），`Esc` 暂停 / 继续
- **百刃**：`WASD` 移动，`空格` 释放技能；支持触屏虚拟摇杆（手机 / 平板）

> 具体按键以游戏内提示为准。
