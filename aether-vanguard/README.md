# 源能斗士 AETHER VANGUARD · 引擎重制版

把单文件 Canvas2D 版（仓库根目录 `index(1).html`）重制为 **Phaser 4 + TypeScript** 工程：WebGL 渲染、元气骑士式像素 2.5D、动态光照与后处理、开源 CC0 美术素材。

## 运行

```bash
cd aether-vanguard
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm test           # 单元测试（Vitest）
npm run build      # 类型检查 + 生产构建到 dist/（静态文件，可直接部署到 GitHub Pages）
```

需要 Node 20+ 和支持 WebGL 的浏览器。

## 这一版做了什么

- **渲染引擎**：Phaser 4（WebGL）。`smoothPixelArt` 保证像素在缩放与旋转下都清晰；画布按 DPR 渲染，Retina 屏同样锐利。
- **伪 3D**：墙体有墙顶与南向砖面，所有物体按脚底 y 深度排序（走到墙后/屋后会被遮挡），角色有椭圆投影。
- **光照与后处理**：火把、路灯、水晶、熔岩缝、技能、投射物、爆炸都是动态光源；相机辉光（阈值 + 模糊叠加）、暗角；每个副本有独立的色调、环境光与飘屑粒子。
- **人物与素材**：12 个职业基于 0x72 Q 版英雄换色，各有专属武器（拿在手上、随鼠标旋转，挥砍/突刺/后坐动画）、盾牌和元素光环粒子；装备的武器会显示在角色手上；24 种怪物（含 NA 四向怪）与 4 个首领；30+ 种技能特效序列帧；城镇建筑与植物。详见 `public/assets/CREDITS.md`。
- **玩法修复（对应《游戏3.txt》改版意见）**：怪物流场寻路 + 贴墙滑动，不再卡墙；无限刷怪；左键攻击、法师远程；状态叠层有上限；奥义同时只能一个；当前职业 Lv10 即可融合（只一次）；多角色存档；每个副本 3 层，走到出口即进下一层；铁匠强化 + 材料掉落；背包有格子上限；仓库；药剂商；秘境试炼；变体房间（补给泉、事件祭坛、精英房）；职业隐藏被动；装备词条保护；原生 Web Audio 合成音效与氛围音乐。
- **工程化**：模拟层（`src/game`、`src/world`）与渲染层（`src/view`）分离，固定 60Hz 步长；287 个单元测试覆盖碰撞、寻路、地图生成、成长、战斗、怪物 AI、音频与 UI 逻辑（含分区审查发现的跨模块 bug 的回归测试）；`tools/e2e.mjs` 用无头 Chrome 跑完整流程冒烟。

架构说明见 `docs/ARCHITECTURE.md`，开源方案调研结论见 `docs/RESEARCH.md`。

## 目录

```
src/
  data/    纯数据（职业、技能、技能树、怪物、副本、物品、剧情）
  core/    随机数、工具函数
  world/   网格地图、碰撞、流场寻路、视线迷雾、地图生成
  game/    模拟层：状态、成长、装备、战斗、技能、怪物 AI、刷怪、掉落、场景流转、主循环
  view/    Phaser 渲染：素材加工、2.5D 地图、角色、特效、主题
  scenes/  Boot / Game 场景
  ui/      DOM 界面：标题与角色槽、HUD、各类面板、商店、触屏
  audio/   Web Audio 合成音效与程序化音乐
tests/     Vitest 单元测试
tools/     shot.mjs：用本机 Chrome 无头截图/录制操作步骤（调试用）
```
