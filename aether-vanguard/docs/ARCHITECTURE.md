# 源能斗士 AETHER VANGUARD · 引擎重制版架构说明

> 渲染：Phaser 4（WebGL，`smoothPixelArt`）· 语言：TypeScript · 构建：Vite · 测试：Vitest
> 旧版单文件 `../index(1).html` 保留不动，作为数值与行为的对照基准。

## 1. 分层

```
src/
  config.ts          全局常量（TILE=32 世界单位、视野、固定步长、层数、背包格数…）
  data/              纯数据表（从 legacy 原样迁移 + 类型）。改数值不改 id，保证存档兼容
  core/              rng（可播种 Mulberry32）、util（数学/颜色/转义）
  world/             网格地图、圆形碰撞、流场寻路、视线/迷雾、地图生成（纯函数）
  game/              模拟层：状态 G、实体类型、成长、装备、战斗、技能、怪物 AI、刷怪、掉落、场景流转、主循环
  view/              渲染层（Phaser）：地图 2.5D 绘制、角色/怪物精灵、特效、光照、相机
  scenes/            Phaser 场景：Boot（加载）、Game（世界）、Hud（屏幕 UI）
  ui/                DOM 覆盖层：标题/角色槽、各类面板、商店、铁匠、仓库、死亡页
  audio/             原生 Web Audio 合成音效（不引第三方库）
```

**单向依赖**：`data ← core ← world ← game ← (view | ui | audio)`。
模拟层（`world/`、`game/`）**不引用 Phaser、不碰 DOM**，因此可以在 Vitest 里无头测试，也为以后的联机同步/回放留出空间。

## 2. 模拟层约定

- **坐标与单位**：世界坐标沿用 legacy（1 格 = 32 单位），所有射程、半径、速度数值照搬不用换算。
  - 速度一律是「世界单位/秒」。legacy 中敌人速度是「每帧像素」，移植时 ×60；投射物 `v` 同样 ×60。
- **固定步长**：`game/sim.ts` 的 `step(SIM_DT)` 以 60Hz 推进（`SIM_MAX_STEPS` 防掉帧螺旋）。打开面板时单机暂停。
- **随机数**：战斗与掉落用 `core/rng.ts` 的全局 `rng`；地图生成必须用 `new Rng(seed)`（同种子同地图，联机各端一致）。
- **实体**：全部是 `game/types.ts` 中的纯数据接口，按 `id` 被渲染层同步。用 `nextId()` 分配 id。
- **表现事件**：一次性效果（刀光、爆炸、飘字、震屏、音效、提示条…）通过 `emit()` 推入 `G.events`，渲染/音频层每帧消费后清空。持续存在的东西（投射物、伤害区域、掉落）由渲染层直接读数组绘制。
- **碰撞**：所有位移都走 `world/collision.ts` 的 `moveCircle`（击退、互推、召唤、冲刺也不例外），彻底杜绝“怪物卡墙”。
- **寻路**：怪物共享 `G.flow`（以玩家为源的流场），有视线时直线逼近，否则沿流场下降。
- **视线**：索敌、射击、光束、迷雾统一走 `world/los.ts`。不对墙后的目标开火。
- **迷雾**：`explored`（永久）+ `visible`（当前视野）双掩码；小地图/大地图/Boss 提示只显示已知信息，Boss 在未探索区域时只给方向箭头与文字提示。

## 3. 规则定案（团队需求冲突时以最新的《游戏3.txt》为准）

| 冲突点 | 定案 |
|---|---|
| 融合条件（R09） | **当前职业 Lv10** 即可融合，弹窗确认，**只能融合一次**，不再赠送 6 技能点（改为 +2） |
| 切换职业（R10） | **不能切换职业**；改为多角色存档槽（4 个），每个角色独立成长 |
| 过关方式（R40） | 走到出口即进下一层，不必清怪；第 3 层为首领层，击败首领开启回城传送阵 |
| 攻击方式（R28/R29） | **左键朝鼠标方向攻击**（按住连发）；自动攻击作为可选开关（默认关闭，触屏默认开启） |
| 迷宫层数（R41） | 每个副本 3 层；主城传送阵可去不同副本 / 竞技场 / 秘境 |
| 刷怪（R34） | 刷怪器无限补怪，维持存活上限，随层数/副本提高 |
| 血量与回复（R58） | 角色基础血量降低，脱战后自动回血 |

## 4. 渲染层要点（Phaser 4）

- `render.smoothPixelArt = true`：像素放大/旋转都清晰且不闪烁（Phaser 4 官方像素指南推荐）。
- 画布尺寸 = 窗口 CSS 尺寸 × DPR（FIT 模式），Retina 屏同样清晰；世界相机缩放使可见范围约 640×400 世界单位。
- 2.5D：墙体有顶面 + 正面立面，所有立体对象按脚底 y 深度排序；角色有椭圆投影、受击闪白、攻击前摇、残影。
- 光照：Phaser 4 Lighting 组件（`setLighting(true)` + 场景点光源），火把/技能/投射物/出口都是光源；环境光按副本主题变化。
- 后处理：相机 ParallelFilters 辉光（阈值 + 模糊 + 叠加）、暗角、按主题的调色。
- HUD 在独立的 Hud 场景（不受世界相机缩放/震屏影响）；面板是 DOM 覆盖层（大量中文、滚动、表单更合适）。
